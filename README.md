 
iOS To-Do List App
Welcome to the iOS To-Do List App! 🎉

This is a simple and intuitive To-Do List application built using SwiftUI. Whether you're managing your tasks for the day or tracking longer-term goals, this app will help you stay organized and productive.

Features
Add, edit, and delete tasks easily
Track tasks with checkboxes
Simple, user-friendly design powered by SwiftUI
Light and dark mode support

Project Structure
This project is organized into 8 parts:

Main: The starting point for the app, with basic structure and UI components.
Part_1 to Part_6: Progressive additions to the app, covering features like task management, design improvements, and more.
Part_7: This part contains the completed version of the app, with all features fully implemented.

Getting Started
Clone this repository to your local machine.
Open the project using Xcode.
Build and run the app on your simulator or real device.
